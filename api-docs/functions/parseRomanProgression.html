    • parseRomanProgression(
          progression: string,
          keySymbol: string,
          tuning?: TuningSystem,
          octave?: number,
      ): Chord[]

      Parses a Roman numeral progression in a given key into an array of Chord objects.

      Supported syntax:

      • Uppercase numerals = major quality: I, IV, V
      • Lowercase numerals = minor quality: ii, iii, vi
      • 7 suffix: degree-sensitive - ii7 = m7, V7 = dom7, I7 = maj7
      • Other suffixes delegate to normalizeSuffix: IVmaj7, iiø, etc.
      • Chromatic accidentals: bVII, #IV
      • Applied chords: V7/ii, IV/V
      • Tritone substitution: subV7, subV7/ii

      Example: parseRomanProgression("ii7 V7 subV7/ii Imaj7", "C major")

      Note: Applied chord names use 12-TET note names regardless of the target tuning. This is a known limitation for non-12-TET tunings.

      Parameters

      • progression: string

        Space- or hyphen-separated Roman numeral tokens.

      • keySymbol: string

        Key and scale type, e.g. "C major", "D dorian".

      • tuning: TuningSystem = TET12

        Target tuning system (default: 12-TET).

      • octave: number = 4

        Octave for root notes (default: 4).

      Returns Chord[]
