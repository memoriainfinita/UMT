    Class ToneRow

    Twelve-tone / serial composition tools. All operations work in pitch-class space (0–11, C=0 convention is NOT required; the row is treated as an ordered sequence of pitch classes modulo 12).

    isCombinatorial

    • isCombinatorial(): "I" | "P" | "RI" | null

      Tests whether the row is combinatorial with itself under one of the standard operations. Returns the operation type ('P', 'I', 'RI') or null.

      • 'P': some transposition of P starts with the second hexachord of P(0).
      • 'I': some inversion starts with the second hexachord of P(0).
      • 'RI': some retrograde inversion starts with the second hexachord of P(0).

      Returns "I" | "P" | "RI" | null
