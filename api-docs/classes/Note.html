    Class Note

    A single pitch in a given tuning system.

    Position is stored as stepsFromBase, an integer offset from A4 (step 0) within the tuning. The same step number means different frequencies in different tuning systems.

    name

    • get name(): string

      The full note name including octave number (e.g. "C4", "Bb3", "F#5"). In 12-TET, the octave follows scientific pitch notation: C4 = middle C. Uses the flat/sharp preference set at construction. For an explicit override use getName({ preferFlats: true/false }).

      Returns string

      Example

      UMT.parseChordSymbol('Cmaj7').getNotes().map(n => n.name)
      // → ['C4', 'E4', 'G4', 'B4']
