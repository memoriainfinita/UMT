    • analyzeSixFour(
          progression: Chord[],
          keySymbol: string,
          index: number,
      ): SixFourAnalysis

      Determines the context of a second-inversion (6/4) chord within a progression. Returns 'none' if the chord at index is not in second inversion.

      • cadential: tonic 6/4 followed by V → I.
      • pedal: bass stays the same across the 6/4 and its neighbors.
      • passing: bass moves by step through the 6/4.
      • arpeggiated: same chord repeats with different inversions.

    StaticcheckVoiceLeading

    • checkVoiceLeading(
          chordA: Note[],
          chordB: Note[],
          ruleset?: "strict" | "contemporary" | "species",
          context?: { chordA?: Chord; chordB?: Chord; keySymbol?: string },
      ): VoiceLeadingIssue[]

      Checks voice leading between two chords. Emits warnings for parallel motion, voice crossing, overlap, and (when context is provided) unresolved tendency tones, hidden/direct 5ths/8ves, false relations, and doubled leading tones.

      Voices are expected to be ordered bass → soprano in both chords.

      Parameters

      • chordA: Note[]
      • chordB: Note[]
      • ruleset: "strict" | "contemporary" | "species" = 'strict'

        'strict': Bach chorale-style - all standard prohibitions enforced.

        • 'contemporary': jazz/pop - relaxes parallel 5ths/8ves and leaps.
        • 'species': minimal - no parallels, no crossing, no overlap. Full species counterpoint rules live in the counterpoint module (future phase).
      • Optionalcontext: { chordA?: Chord; chordB?: Chord; keySymbol?: string }

        Optional harmonic context enabling tendency-tone and false-relation checks.

      Returns VoiceLeadingIssue[]

    StaticclassifyModulation

    • classifyModulation(
          chordsA: Chord[],
          chordsB: Chord[],
          keyA: string,
          keyB: string,
      ): "chromatic" | "direct" | "pivot" | "enharmonic" | "common-tone"

      Classifies the type of modulation between two key areas based on the transitional chords.

      • 'enharmonic': both keys have identical pitch class content.
      • 'chromatic': the tonic notes are one semitone apart.
      • 'pivot': a chord in chordsA is diatonic to keyB.
      • 'common-tone': the last chord of A and first chord of B share at least one PC.
      • 'direct': abrupt modulation, no smooth transition detected.

      Parameters

      • chordsA: Chord[]
      • chordsB: Chord[]
      • keyA: string
      • keyB: string

      Returns "chromatic" | "direct" | "pivot" | "enharmonic" | "common-tone"
